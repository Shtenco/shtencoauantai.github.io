# Financial OS V2 public showcase

Standalone public-facing prototype for the SINERGY next-generation financial architecture.

The root `index.html` is intentionally untouched. This page lives at `financial-os-v2/index.html` only inside the new feature branch until explicitly reviewed and promoted.

The page presents concepts, not guaranteed returns or production availability. It distinguishes market value from hard backing and states that live fiat/CBDC/crypto connectivity depends on authorised providers and compliance.
